# 第四版单日预测的耗时与一致性

预测 **2024-01-01 的南平日均 GloFAS 流量**，两个入口均给出 **171.860478808141 m³/s**。本机同一 Python 进程内，各运行四次，原入口耗时中位数 **5.366 秒**，快速入口 **3.864 秒**，减少 **1.502 秒（27.99%）**。

第四版冻结的 `prior`、`local`、`ar` 权重分别为 0.5、0.5、0。快速入口 `stable_v4(data, start, stop, artifacts=None)` 只计算有非零权重的分支，各分支仍调用第四版原有拟合和预测函数。每次调用均从磁盘读取冻结配置，核对三个分支的配置及相关源代码签名，保留 2021-01-01 和 2022-01-01 两个原始训练边界。返回按目标日期索引的预测 Series；`artifacts` 可指向含 `frozen.json` 的第四版 `results` 目录，默认使用相邻的 `minjiang-v4`。

## 同条件实测

原入口取 `minjiang-v4/run.py` 的 `frozen_predict(...).prediction`。两者使用同一份组员数据、同一组冻结文件和相同日期。2021 年全年 365 天、2022–2023 年 730 天，以及延长至 2024-01-01 的 731 天逐日比较，各区间最大绝对差均为 **0**。

计时时两条路径都以 **2022-01-01** 为起点，重新读取原始表和拟合模型，重建至 **2024-01-01** 的完整轨迹后返回最后一天。相同查询各预热一次，再交错切换顺序。线程池限制为 2。下列耗时包含每次签名检查、数据读取、特征构建、模型拟合和预测。Python 解释器启动与模块导入在计时之前完成，代码不跨请求缓存预测。
