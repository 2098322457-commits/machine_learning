# 第六轮比较规则

预测目标仍是南平次日 GloFAS 日均流量。三种新模型分别考察河道传播、气象与雨区移动、树模型的非线性响应。先在 2018–2020 三个年度折内选择每个模型自身的配置，再与第四版的日预测比较。每折训练数据只来自该目标年之前。

1. 在第四版有完整折外预测的 2019–2020 年，将每个新模型分别按 25%、50%、75%、100% 加入第四版。最多比较 12 种组合。用同一批 731 个日期计算 RMSE 和 MAE。
2. 进入外层验证需要同时满足三个条件：两年合并 RMSE 至少改善 2%，两个单年各自的 RMSE 均不高于第四版，合并 MAE 至多上升 3%。满足条件的组合中冻结合并 RMSE 最小的一项。若均未达标，直接保留第四版。
3. 在 2021 年仅检验这一个冻结组合。若整体 RMSE 比第四版至少低 1%、MAE 至多上升 3%、最高 5% 流量日的 RMSE 至多上升 5%，则采用候选方案进入两年历史测试。若验证未通过，保留第四版并停止新的测试集比较。模型设计阶段已知往期报告的历史分数，这些历史时期不能充当全新盲测。
4. 同一版的误差区间另行评估。按最近 365 天的预测误差给次日预测配 90% 经验区间，比较固定误差尺度和根据前一日流量调整尺度两种做法。误差区间不参与点预测的筛选。
