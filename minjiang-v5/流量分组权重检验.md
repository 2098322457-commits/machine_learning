# 流量分组能否改善 V4 等权预报

**保留 V4 固定等权。** 用 2019 全年估计分组权重后，逐日预测 2020 年。两个方案用完全相同的 `prior`、`local` 分支预测与 366 个目标日。动态分组使整体 RMSE 增加 0.45%。该分支没有进入 2021 年或后续测试选型。

| 2020 年前推对照 | RMSE，m³/s | MAE，m³/s | 高流量 RMSE，m³/s |
|---|---:|---:|---:|
| V4 固定各 50% | **61.604** | 29.367 | 153.518 |
| 按前一日流量和涨落分组 | 61.881 | **29.340** | **153.104** |

高流量统计用 2020 年真实目标的第 95 百分位划分，只用于结果描述。事前规定推广需要满足三点：总体 RMSE 至少降低 1%，MAE 不增加，RMSE 降幅的配对区块重采样 95% 区间下端大于零。以 14 个连续日为一块，循环取样 4,000 次，得到降幅区间 **−1.420% 至 +0.645%**。局部 MAE 和高流量误差的微小变化没有带来总体 RMSE 提升。

## 权重估计

目标日为 T 时，状态使用南平源日 T−1 的模拟流量，并与 T−4 比较判断涨落。所有输入都可在作业的日终可用假设下取得。流量高低阈值只在 2019 年训练样本上求中位数，得到 385.37 m³/s。四个组各自以平方误差最小化估计权重，并向 50% 收缩。惩罚强度为 90 乘以全体训练样本的两分支预测差平方均值。将 `prior` 权重限制在 25% 至 75%，另外的权重分配给 `local`。

| 2019 年状态 | 训练天数 | `prior` 权重 |
|---|---:|---:|
| 较低、平稳或回落 | 148 | 50.79% |
| 较低、上涨 | 34 | 49.87% |
| 较高、平稳或回落 | 101 | 67.12% |
| 较高、上涨 | 82 | 58.19% |

2018 年的 V4 `prior` 折外预测不完整，因此门控只使用 2019 年的 365 个历史样本拟合。2020 年目标仅在对照评分中使用。V4 底层分支的配置曾用 2018–2020 年的开发期选择，本试验衡量的是在给定这些折外预测的条件下，新增的权重规则能否从 2019 年推广到 2020 年。它只有一个完整的跨年检验。

## 复现

```powershell
Set-Location 'D:\桌面\机器学习导论\minjiang-v5'
..\minjiang-forecast\.env312\Scripts\python.exe gate.py
```

源数据是组员 `data/glofas_daily_discharge.csv` 和 V4 的 `results/validation_oof.csv`。读取门控状态时，流量数值最晚取到 2020-12-30。脚本拒绝含 2020 年之后预测日期的开发表。`gate_results/gate_2020_forward.csv` 含逐日的两路预测、状态、权重、目标和两种合成预测。`gate_2020_scores.csv`、`gate_decision.json` 分别保存汇总和保留固定权重的决策。

如需执行冻结的决策，可调用 `gate.locked_blend(data, out, frame)`。其中 `frame` 只需提供按目标日索引的 `prior` 和 `local` 两列，`out` 指向 `gate_results`。当前决策返回两路预报的算术平均。
