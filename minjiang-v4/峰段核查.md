# 南平日均流量的高流量过程

以 2014-02-01 至 2020-12-31 的 2,526 个可训练目标日为参照，取南平 GloFAS 日均流量的第 95 百分位 **3,602.715 m³/s**。固定这一阈值后，分别检查 2021 年外层保留期及 2022–2023 年历史测试期。这里的流量真值是组员仓库里的模拟日均流量。

| 时段 | 高流量日 / 总天数 | 连续峰段数 | 组员 Ridge 高流量日 RMSE | 第四版高流量日 RMSE | 组员命中峰日 | 第四版命中峰日 |
|---|---:|---:|---:|---:|---:|---:|
| 2021 | 20 / 365 | 1 | 314.03 | 320.02 | 1 / 1 | 1 / 1 |
| 2022–2023 | 37 / 730 | 3 | 309.69 | 192.90 | 2 / 3 | 2 / 3 |

真实日均流量达到阈值的相邻天组成一段，低于阈值一天即分段。四段都持续至少两天。RMSE 使用段内逐日误差，单位为 m³/s。评估峰值和峰日时，给每段首尾各留最多两天，以便识别提前或滞后；不跨评估期。如相邻段的扩展窗口相遇，按日与最近段的距离划分，等距日给较早段。相同最大值取最早日。偏差为预测峰值减真实峰值，日期偏移取预测峰日减真实峰日。

| 高流量日期 | 天数 | 真实峰日 / 流量 | 组员峰值偏差 / 日偏移 | 第四版峰值偏差 / 日偏移 |
|---|---:|---|---|---|
| 2021-05-20 至 06-08 | 20 | 05-22 / 7,567.33 | +492.60 / 0 | +382.71 / 0 |
| 2022-05-14 至 05-18 | 5 | 05-14 / 4,741.42 | +180.06 / +1 | +224.93 / 0 |
| 2022-05-28 至 06-26 | 30 | 06-15 / **11,747.98** | +776.33 / 0 | +542.03 / 0 |
| 2023-05-08 至 05-09 | 2 | 05-08 / 4,196.59 | +136.43 / 0 | +15.57 / +1 |

2022–2023 年的改善主要集中在最长的 30 天过程。这一段占全部 37 个高流量日的 81%，第四版段内 RMSE 从 336.55 降到 198.56。其余两个短段内第四版的逐日 RMSE 均高于组员模型。2021 年只有一个峰段，第四版的峰高误差较小，整段逐日 RMSE 却高了 5.99 m³/s。两段资料合计只有四个按阈值识别的峰段，无法据此推断在更多洪峰事件中的胜率。

在 `minjiang-v4` 中运行 `..\minjiang-forecast\.env312\Scripts\python.exe .\peak_audit.py`。脚本核对评估期间逐日真值，打印上述计数与指标，并生成 [峰段逐行明细](results/peak_events.csv)。CSV 同时列出真实峰日当天的预测误差，便于区分峰高偏差和到达时间偏移。
