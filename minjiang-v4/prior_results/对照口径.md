# V3 对照的重新选参

对照目标是南平断面次日平均流量。以目标日为索引，从组员原始 CSV 筛出 2020-12-31 及更早的记录，写入临时数据目录，再调用 V3 的特征和估计函数。选参无需读取原有 V3 结果。每个预测日使用前一日结束时已有的完整日数据，公开再分析产品的实际发布时间仍是单独的可用性假设。

验证窗口为 2018、2019、2020 三个完整自然年。每折仅用更早目标日训练，逐日输出共 1,096 条。各候选共用目标日，按全部验证日的 RMSE 选参数。依次比较 63 组河道特征与正则组合、30 组尺度模型、9 组核模型和 15 组以 0.25 为步长的融合权重。残差校正在 2019、2020 两折比较四种强度，包括关闭校正。每折只用之前各折的基模型预测误差拟合校正器，当日校正可以使用昨天已知的误差。

冻结结果为河道模型 network_storm（α=1）和门控尺度模型（α=500，流量权重指数 2）等权融合。核分支选中带宽 16、惩罚 0.3，融合权重为零。残差校正 α=1500。逐日文件 prior_oof.csv 中的 base 是融合分支的折外预测，prior 是校正后预测。2018 年缺少更早折外误差，prior 列留空，后两年的有效天数为 731。这些折外值供选参和融合使用，报告独立检验时应使用后续年份。

在工作区根目录复现：

```powershell
.\minjiang-forecast\.env312\Scripts\python.exe .\minjiang-v4\prior.py freeze
.\minjiang-forecast\.env312\Scripts\python.exe .\minjiang-v4\prior.py predict --start 2021-01-01 --stop 2021-12-31
.\minjiang-forecast\.env312\Scripts\python.exe .\minjiang-v4\prior.py predict --start 2022-01-01 --stop 2023-12-31
```

预测区间的首日决定拟合截止。2021 年评估在 2020 年末训练一次基模型和校正器。2022–2023 年评估使用相同超参数，基模型用截至 2021 年末的标签重新训练一次，校正器的折外档案补入 2021 年以原冻结参数预测的完整序列。两年评估期间模型系数固定，滞后观测和滞后误差随预测日期滚动更新。每日结果保留 target、base 和 prior 三列。接口另核对 V3 源文件和折外档案的哈希。
