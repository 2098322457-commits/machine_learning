# 相似水文过程的南平次日日均流量预报

本分支只读取组员 `data/glofas_daily_discharge.csv` 的五个断面日流量和 `data/openmeteo_hourly_precipitation.csv` 的十二站小时降水。目标是南平次日 GloFAS 日均流量。预报假定当天全部流量与降水汇总在日终可用；仓库未记录每个产品在历史预报时刻的发布版本。

## 验证如何使用

建模数据在计算滞后、标准化、近邻和回归之前截断至 2020-12-31。三折都从 2014-02-01 起训练，分别截止到 2017、2018、2019 年底，用来预报下一整年。每折的参数在年初拟合一次，年内每个目标日只使用其前一天及更早的数据。每个验证目标日有且只有一条预测，其真实目标值未进入该折训练。

| 验证年 | 样本天数 | 入选模型的 RMSE（m³/s） |
|---|---:|---:|
| 2018 | 365 | 49.29 |
| 2019 | 365 | 136.82 |
| 2020 | 366 | 61.84 |
| **合并** | **1,096** | **91.21** |

选择依据是三年逐日误差平方合计后开方的 RMSE。年份差异较大，例如 2019 年远难于 2018 年。三折用于选择超参数，因此合并指标仍属于开发验证成绩。新版的 2021 年及以后的评估由上层在冻结后另行计算。

## 模型怎样预测

1. 全局方程拟合明日流量与当前流量之差，按当前及前几日南平流量构成的尺度归一化。驱动变量包括各支流流量、近四日的日变化、分区降雨、每六小时的小计和湿润度。用三次 Bernstein 多项式使流量与降雨的系数随水量大小和涨落阶段平滑变化，再用带正则的 Ridge 拟合。
2. 在预报时，将当前日与训练期每一天按五个断面的流量比例、涨落速度和近期分区降雨进行比较。距离和标准化只依据可用训练资料。在固定数量的历史近邻内，对全局模型的训练残差作局部线性回归，修正当日流量变化预测。局部样本按距离加权，局部斜率向零收缩。
3. 每组候选固定全局正则、近邻数和局部惩罚。比较了三个全局正则强度（10、100、500）、三个非零近邻数（60、180、450）与两种局部惩罚（0.03、0.3）的 18 组组合，另加 3 组纯全局对照。按合并 RMSE 选中的为全局正则 100、450 个近邻、局部惩罚 0.3。合并 MAE 为 33.62 m³/s，相同全局正则、去掉局部校正时的 RMSE 和 MAE 分别为 91.80 和 36.53 m³/s。

## 复现与调用

```powershell
Set-Location 'D:\桌面\机器学习导论\minjiang-v4'
$py = '..\minjiang-forecast\.env312\Scripts\python.exe'
& $py candidate.py validate
```

`candidate_results/candidate_validation.csv` 保存 21 个候选的合并验证指标，`candidate_folds.csv` 给出各年度结果，`candidate_oof.csv` 保存 1,096 个目标日的标签和预测。开发截止日、选中的配置和代码 SHA-256 写入 `candidate_choice.json`。复现需要 Python、NumPy、pandas、SciPy、scikit-learn、threadpoolctl，可沿用项目环境。

Python 接口为 `candidate.validate(data,out)` 和 `candidate.locked_predict(data,out,start,stop,delay_days=0)`。后者核对代码散列，按给定时间段的首次起报时刻拟合一次，返回按目标日排序的预测 Series。它不需要该时间段的标签作为拟合目标；当某一验证年的过去流量逐日成为可用观测时，可用于之后日期的滞后输入。起止时间相同即为单日预测。额外输入延迟可设为一天，届时目标日 T 的最新可用源日期变为 T−2，重新训练的标签也遵守同一可用边界。
